# Readback Check — 이해가 엇갈린 합의 잡아내기

캐릭터 문구: **“오빠, 내가 한 말 이해한 거 맞아?”**
중립 문구: **“잠깐, 이 선택의 결과를 같은 뜻으로 이해했는지 하나만 확인할게요.”**
영어 예시: **“Wait—what happens if this fails halfway through?”**

사용자가 장난스러운 캐릭터를 원하면 첫 문구를 쓸 수 있다. 실제 질문에는 확인할 결과를 붙인다.
사용자가 주제를 모른다거나 잊었다는 진단을 내리지 않고, 답변에 드러난 기대와 결정의 결과를 대조한다.

## 언제 확인하나

아래 조건 중 하나가 있으면 질문 하나로 확인한다.

- “추천대로”, “그냥 해”, “알아서”가 중요한 범위 제외·데이터 손실·권한 경계·되돌리기 어려운 비용의
  첫 선택에 대한 답이며, 앞선 발언에도 그 결과를 이해하거나 위임한 근거가 없다.
- 추천을 받아들인 뒤 해당 선택이 보장하지 않는 결과를 기대한다.
- 이전 결정과 현재 답이 어긋나는데 의도적인 변경인지, 결과를 다르게 이해한 것인지 불분명하다.

건너뛸 경우:

- 사용자가 비용·실패 결과를 이미 구체적으로 말하고 선택 또는 위임했다.
- 충분히 설명한 선택에 대해 사용자가 범위를 정해 판단을 맡겼다.
- 작고 되돌리기 쉬운 구현 세부사항을 위임했다.
- 같은 결과를 확인한 기록이 있고 그 전제가 바뀌지 않았다.

짧은 답변, 기술 용어를 모르는 것, 추천을 요청하는 것 자체는 이해 부족의 근거가 아니다.

## 질문하는 방법

1. 방금 받은 답변과 아직 확정하지 못한 쟁점을 먼저 저장한다. 읽어본 기록이 있으면 회차·결정 ID를 연결한다.
2. 선택의 대가를 일상적인 말로 한 문장 설명한다. 새 대안을 전부 설계하게 하거나 정의를 암기시키지 않는다.
3. **구체적인 상황 하나**에서 어떤 결과를 기대하는지 묻는다. 그 회차의 전체 질문 한도 1~2개에 포함한다.
4. 답변을 기록하고 기대가 맞으면 진행한다. 오해가 드러나면 짧게 풀어 설명한다.
   사용자가 이해하려고 할 때 같은 상황을 한 번 더 확인할 수 있다. 보류·중단·위임 요청이면 반복 질문을 멈춘다.

예시:

> “로컬 임시 저장을 없애면 재시작 뒤에는 초안을 되살릴 수 없어요.
> 저장 전에 앱이 꺼졌을 때, 초안은 어떻게 되는 걸로 이해했어요?”

답변 “없어져도 괜찮아. 초안 복원은 v2로 빼자”는 선택의 결과를 구체화한다.
답변 “그래도 복원은 되지?”는 이해가 엇갈린 부분을 드러낸다. 이미 합의한 것으로 처리하지 않는다.

## 어떻게 기록하나

테마 파일의 이해 확인 기록에 관련 결정, 질문 회차, 확인한 결과, 실제 답변, 처리 상태를 남긴다.

| 상태 | 기록할 근거 |
| --- | --- |
| `confirmed` | 사용자가 결과를 자기 말로 설명하거나 구체적인 대가를 선택한 답변 |
| `delegated` | 위임 범위와 근거가 되는 발언. 이해가 입증됐다고 표현하지 않음 |
| `unresolved` | 무엇이 여전히 다르게 이해되거나 결정되지 않았는지, 연결된 Q ID |
| `not-needed` | 기존 회차의 확인 근거 또는 이번 선택이 작은 구현 세부사항이라는 이유 |

상태는 사용자 능력의 점수가 아니다. 이해·위임의 근거를 결정과 함께 보존하기 위한 기록이다.
확인 질문을 하지 않았다면 하지 않았다고 남긴다. 모든 결정마다 빈 기록을 만들 필요는 없다.

## 위임·거부·모른다는 답

- **“모르겠어. 설명해줘.”** 결과를 쉬운 예로 설명하고 추천을 제공한다. 설명을 들었다는 이유만으로 합의를 만들지 않는다.
- **“손실 가능성은 알겠어. 주기는 네가 정해.”** 결과는 확인됐고 세부 선택은 위임됐다. 이를 기록하고 진행한다.
- **“시험 보듯 묻지 말고 네가 판단해.”** 질문을 멈추고 위임된 범위의 기본값과 이유를 기록한다.
  다른 필수 결정이 해결돼 있다면 이해 확인을 거절했다는 이유만으로 명세를 차단하지 않는다.
- **“그건 나중에.”** 보류된 결정과 영향 범위를 남긴다. 구현을 막는 결정이 실제로 남아 있으면 명세는 `incomplete`다.

새 승인을 받기 위한 절차로 쓰지 않는다. 침묵·기본 선택·형식적 동의를 이해 증거로 바꾸지 않는다.
